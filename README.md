**Live Site:** [divyarajchauhan.in](https://www.divyarajchauhan.in/)

## 1. Overview

This repository powers the official portfolio website of **Divyaraj Chauhan**, showcasing production web applications, bespoke design systems, full-stack systems engineering, and creative technology experiments.

Built with a bold brutalist-editorial design language, the portfolio emphasizes tactile micro-interactions, custom WebGL canvas shaders, physics-based simulations, fluid typography, sound design, and comprehensive project case studies.

---

## 2. Key Features

- **Selected Web Work Gallery:** Desktop split-column showcase with reverse alternating layouts and an interactive 3D circular card carousel on mobile screens.
- **Deep-Dive Case Study Portal (`websites.html`):** In-depth engineering breakdowns, architecture specifications, and live preview galleries for ChemOps ERP, The Sky Box, Abhushan Jewellery, DC Detailing, and KXM Clothing.
- **Dedicated 8Bit Creatives Case Study (`8bit-creatives.html`):** Immersive interactive study featuring embedded interactive physics simulations and multi-device viewports.
- **Audio Experience Controller:** Custom sound effects engine providing tactile audible clicks and hover feedback for interactive elements.
- **Custom Interactive Cursors:** Physics-based magnetic custom cursor responding to hover targets, links, and cards.
- **Interactive Resume & Terminal:** Dedicated digital resume (`divyaraj-resume.html`) with interactive career milestones and downloadable PDF.
- **Performance & SEO Hardened:** Zero-framework static architecture delivering near-instant page transitions, strict security headers, and structured schema markup.

## 3. Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Markup & Layout** | Semantic HTML5 & Modern Layout Architecture |

## 5. Getting Started

### Local Setup
The portfolio is designed as a buildless, dependency-free static website:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/diu-ctrl/Divyaraj-Portofolio.git
   cd Divyaraj-Portofolio
   ```

2. **Serve locally:**
   Run any static local web server:
   ```bash
   # Using npx serve:
   npx serve .

   # Or using Python:
   python -m http.server 3000
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
